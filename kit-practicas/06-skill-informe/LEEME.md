# 06. El informe de una página

En esta práctica le pides al agente un informe y, en vez de explicarle cómo lo
quieres, le dices que siga las reglas de la casa, que ya están escritas.

- `manual_estilo.md`, con las ocho reglas del informe ejecutivo de una página.
- `plantilla_informe.md`, con el esqueleto del informe.
- `presupuestos_limpio.csv`, que es el resultado de la Práctica 4 ya hecho, con
  119 observaciones de 20 municipios entre 2019 y 2024 (falta Archidona en
  2020, que no venía en los datos). Son datos simulados.

Cuando unas reglas así se empaquetan para que el agente las use solo, sin que
se lo recuerdes, se llaman **Skill**. Una Skill es una carpeta con un fichero
`SKILL.md` y los ficheros de apoyo, y el mismo formato sirve en GitHub Copilot,
en Claude y en otros agentes. Convertir este manual en una Skill es el reto
para casa de la Práctica 7.

Las instrucciones paso a paso están en el cuaderno de la Sesión 2.
